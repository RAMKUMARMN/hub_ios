# Project Copilot Skills

This folder contains Copilot Skill templates tailored to iOS/Swift development for this repository. Use these SKILL.md files as prompt-engineering helpers when interacting with Copilot or AI assistants.

Included skills:
- ios
- swift
- ui-testing
- project-structure
- agent-customization

How to use:
- Provide the requested context in the SKILL.md "Context to provide" sections when invoking an AI assistant.
- Prefer small, test-backed patches in responses.

If you want more specialized skills (e.g., SwiftUI, Combine, CoreData), tell me which areas to add and I'll create them.
