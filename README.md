# iOS — CixioHub Mobile (Flutter)

> **Important:** CixioHub's mobile app is built with **Flutter** — a single Dart codebase that compiles to both iOS and Android. You do **not** write separate native Swift code. The Flutter project lives in `mobile/` at the workspace root.
>
> This folder (`ios/`) contains the iOS-specific build configuration generated by Flutter (Runner.xcodeproj, Info.plist, etc.). You rarely need to edit files here directly, except for APNs push notification setup.

## iOS-specific setup

### Prerequisites
- macOS only
- Xcode 15+
- iOS 16+ deployment target
- Flutter SDK 3.x
- A physical iPhone or iOS Simulator

### Run on iOS Simulator

```bash
# From the mobile/ directory:
flutter run -d ios

# Or:
open ios/Runner.xcworkspace   # Open in Xcode, then press Run
```

### Release build

```bash
flutter build ios --release
# Then archive and distribute via Xcode
```

## APNs (Push Notifications) Setup

iOS push notifications use **Apple Push Notification service (APNs)**, delivered via **AWS SNS** or **Firebase Cloud Messaging**.

1. In Xcode: go to Runner → Signing & Capabilities → add **Push Notifications** capability
2. Also add **Background Modes** → enable "Remote notifications"
3. On a real device, the app registers with APNs and receives a device token
4. Send this token to the backend on login: `PUT /api/v1/auth/profile` with `{ "device_token": "..." }`
5. The notify service (via AWS SNS or FCM) uses this token to send pushes

> **Note:** APNs does not work on iOS Simulator. Test on a real device for push notifications.
